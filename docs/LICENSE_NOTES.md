# License and provenance notes

ASKV should not use the phrase "entirely open source" as a blanket claim. Individual models, weights, datasets and generated-artifact terms differ.

Maintain a machine-readable inventory with:
- component
- exact version
- repository/model URL
- code license
- weights license
- dataset license
- commercial-use restrictions
- attribution requirements
- date checked

For example, Blender is GPL software, and its Python API is part of Blender; published scripts using bpy therefore have GPL-related obligations. Blender itself states that artwork created with Blender is the user's property. See the official Blender license documentation.

CogVideoX also has model-specific licensing differences between releases; do not assume the repository's Apache-2.0 code license applies identically to every model weight.

Safety models must likewise be recorded by exact checkpoint and license/terms.
